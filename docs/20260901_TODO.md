## 🔍 今日关于"音源直链解析"的调查与根因定论

### 问题现象
用户在 Web 或小爱端点歌，指定了 QQ音乐 (tx) 等，但最终音箱下发的流地址依然总是 `[酷我音乐] 原生接口取链成功` 或回退到酷我。

### 根因分析
1. **官方接口限制**：QQ音乐官方流媒体直链签发（vkey 体系）现在严格校验登录态（匿名 `uin=0` 时返回的 `purl` 恒为空），无法免登录直接获取高品质 mp3 直链。
2. **聚合接口 (GDStudio)**：已下架 `tencent` 平台支持（直接报 400 不支持）。
3. **外部第三方脚本机制**：`lx-v5.js` 等自定义音源本质是将取链外包给个人部署的私有中转服务器，附带了客户端专属签名校验。在 Node.js 服务端沙箱中无法脱离真实客户端环境稳定调用。
4. **当前兜底行为**：当前服务端在当前音源无法取链时，启用了精确跨源匹配（同歌名+同歌手+同时长），因此平滑换到了酷我原声流，保证音箱一定能响。
