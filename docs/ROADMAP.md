# XiaoAi SoundHub (小爱声枢) 演进路线图 (Roadmap)

本文档规划了 XiaoAi SoundHub 后续版本的核心功能演进路线，重点聚焦于 **全屋音箱播放队列可视化**、**设备独立播放列表管理** 及 **跨端智能协同**。

---

## 🎯 v1.1.0 规划重点：音箱多曲目播放列表可视化与交互管理

### 1. 功能背景与需求
* 当用户语音呼叫 *“小爱同学，播放 周杰伦”* 或通过网页点播歌手专辑时，系统后台会搜索并生成包含 20~50 首歌曲的 **音箱专属播放队列（Playlist Queue）**。
* 当前后台已具备自动顺序切歌能力，但在前端尚缺少 **直观查看当前音箱还剩下哪些歌、点击列表任意歌曲插播/跳播** 的可视化交互界面。

### 2. 技术设计方案

#### A. 后端接口扩展 (`PlayScheduler` & REST API)
* **`GET /api/queue?did=xxx`**：
  * 返回指定音箱的完整播放队列数据：
    ```json
    {
      "ok": true,
      "data": {
        "did": "725146300",
        "deviceName": "唯美小爱音箱Pro",
        "currentIndex": 2,
        "mode": "sequence", // sequence(顺序) / random(随机) / loop_one(单曲循环)
        "list": [
          { "id": "1", "name": "晴天", "singer": "周杰伦", "duration": 269 },
          { "id": "2", "name": "七里香", "singer": "周杰伦", "duration": 299 },
          { "id": "3", "name": "稻香", "singer": "周杰伦", "duration": 223 }
        ]
      }
    }
    ```
* **`POST /api/queue/action`**：
  * 支持操作：
    * `jump`：直接跳转并播放列表中第 $N$ 首歌曲 `{ did, action: 'jump', index: 3 }`；
    * `remove`：从音箱队列中移除某首歌曲；
    * `mode`：切换播放模式（单曲循环 / 列表循环 / 随机播放）。

#### B. 前端交互设计 (Web UI & 手机客户端)
1. **播放卡片“查看列表”抽屉按钮**：
   * 在每个音箱的播放控制条右侧增加 `📑 播放列表 (20)` 按钮；
   * 点击后从侧边滑出半透明毛玻璃抽屉（Drawer），实时显示当前音箱的完整歌单。
2. **当前播放曲目动态高亮与跳播**：
   * 列表中正在播放的歌曲带有动态绿色声波跳动图标；
   * 点击列表中任意其他歌曲，音箱立刻平滑切换至该曲目开播。
3. **多设备列表快速切换 Tabs**：
   * 抽屉顶部支持点击音箱标签（如 `[客厅小爱]`、`[卧室小爱]`）瞬间切换查看不同音箱各自的独立播放列表。

## 🚀 未来版本规划一览

### 📦 v1.2.0：带屏小爱音箱深度增强
* **实时动态歌词同步 (LRC)**：
  * 为小米带屏音箱（小爱触屏音箱 / 小爱智能家庭屏）及 Web 端提供毫秒级逐字/逐句歌词滚动渲染；
* **封面背景壁纸生成**：
  * 自动为投播曲目提取高清封面并作为带屏音箱动态背景。

### 📦 v1.3.0：语音收藏与自定义歌单
* **语音口令收藏**：
  * 对着音箱说 *“小爱同学，收藏这首歌”*，自动将当前播放曲目持久化保存至个人收藏夹；
* **专属歌单播放**：
  * 支持 *“小爱同学，播放我的收藏”* / *“播放车载流行歌单”*。

### 📦 v2.0.0：跨端联动与智能家居联动
* **无缝接力（AirPlay-like Transfer）**：
  * 手机端/车机端听到一半的歌曲，一键“碰一碰”或“靠近接力”到指定房间的小爱音箱继续播放；
* **离家/回家自动化广播**：
  * 结合米家门锁或传感器，进门自动触发柔和欢迎广播与背景音乐续播。
