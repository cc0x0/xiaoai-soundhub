# XiaoAi SoundHub (小爱声枢) 演进路线图 (Roadmap)

本文档系统规划了 XiaoAi SoundHub 的长期产品演进路线，重点围绕 **多维度元数据展示**、**沉浸式卡拉OK歌词**、**全屋音箱播放队列管理** 及 **跨端智能协同**。

---

## 🎯 v1.1.0：全景元数据、视觉沉浸与音箱播放列表抽屉

### 1. 🖼️ 当前播放音乐的高清视觉与丰富元数据 (Rich Metadata & Visuals)
* **高清专辑封面与黑胶动效 (Album Cover Art)**：
  * 后台自动提取并回传 500x500 ~ 1000x1000 高清专辑封面图；
  * Web 控制台与手机端支持**黑胶唱片慢速旋转**与**封面主体色彩自适应毛玻璃动态背景**（Apple Music / Spotify 沉浸式视觉风格）；
* **完整元数据信息流 (Metadata Stream)**：
  * **专辑名称**（如《叶惠美》、《1989》）；
  * **音质规格徽标**（如 `320Kbps 高品质`、`FLAC 24-Bit 无损母带`、`Hi-Res`）；
  * **音源平台标识**（网易云、酷狗、QQ 音乐等）；
  * **发行年份与流派标签**。

---

### 2. 🎤 毫秒级动态双语歌词系统 (Real-Time Dynamic Lyrics)
* **多源歌词聚合引擎 (`LyricEngine`)**：
  * 自动为当前播放歌曲拉取标准 `.lrc` 歌词数据；
  * 支持**英文歌曲双语歌词对照**（英文原词 + 优雅中文翻译）；
* **沉浸式歌词随动与全屏卡拉OK**：
  * Web 控制台支持一键切换为 **全屏歌词流模式**（当前唱词高亮放大，上下唱词渐变淡化，鼠标点击任意行可快速跳播至对应时间点）；
  * 小米带屏音箱（小爱触屏音箱、智能家庭屏 6/8/10）支持全屏歌词壁纸渲染。

---

### 3. 📑 音箱播放列表抽屉与交互管理 (Queue Manager)
* **一键呼出当前音箱播放队列**：
  * 点击音箱控制栏右侧 `📑 播放列表 (20)`，滑出半透明毛玻璃歌单抽屉；
* **任意歌曲插播、跳播与拖拽重排**：
  * 列表中正在播放的歌曲带有动态绿色声波跳动图标；
  * 点击列表中任意歌曲即可秒级插播/跳播；
* **多设备列表无缝切换 Tabs**：
  * 支持在 `[客厅小爱]`、`[卧室小爱]`、`[书房小爱]` 之间快速切换查看与管理。

---

## 🚀 未来版本进阶规划 (v1.2.0 ~ v2.0.0)

### 📦 v1.2.0：语音智能问答与时间轴控制
* **语音问歌名**：
  * 🗣️ *“小爱同学，这是什么歌 / 谁唱的？”* $\longrightarrow$ 小爱语音精准播报：*“当前正在为您播放周杰伦的《晴天》，收录于专辑《叶惠美》。”*
* **语音快进 / 倒退 (Range Seek)**：
  * 🗣️ *“小爱同学，快进 30 秒”* / *“倒退 1 分钟”* $\longrightarrow$ 基于 HTTP Range 秒级精准跳转播放位置；
* **播放模式自由切换**：
  * 🗣️ *“小爱同学，单曲循环 / 随机播放 / 列表循环”*。

---

### 📦 v1.3.0：语音收藏与个人云歌单
* **语音一键收藏**：
  * 🗣️ *“小爱同学，收藏这首歌 / 我喜欢这首歌”* $\longrightarrow$ 自动归档至个人“我喜欢的音乐”持久化歌单；
* **第三方歌单秒导入**：
  * 支持粘贴网易云音乐、QQ 音乐公开歌单链接，一键将歌单同步投送至全屋音箱播放。

---

### 📦 v2.0.0：全屋派对模式与智能家居深度接力
* **全屋派对合奏模式 (Whole-House Party Sync)**：
  * 毫秒级网络时钟对齐，让全屋所有小爱音箱**完全无延迟同频合奏**同一首歌曲；
* **跨设备无缝接力 (Seamless Transfer)**：
  * 手机/车机听歌靠近音箱时，一键接力到房间音箱；
* **智能家居情境联动**：
  * 结合米家门锁/人体传感器：离家自动停播，回家自动响起专属欢迎音乐。
